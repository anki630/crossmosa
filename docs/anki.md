# 單字卡（Anki 牌組）

X3 可以用來背單字：把 Anki 的 `.apkg` 牌組在電腦上轉成 `.xdk`，放進 SD 卡，裝置上就能翻卡、評分。
排程跟 Anki 傳統的 SM-2 一樣（學習步驟 1 分、10 分，畢業 1 天，簡單 4 天，一天從凌晨 4 點開始算）。
進度只存在 X3 上，不跟手機或電腦上的 Anki 同步。

## 1. 在電腦上轉換牌組

需要 Python 3 和簡轉繁套件：

```bash
pip install opencc-python-reimplemented
```

```bash
python scripts/anki/apkg2x3.py "H:/我的文件/Anki/新标准日本语 · 初级 (假名到释义) 教材原版发音.apkg" -o out/anki
```

可以一次給好幾個 `.apkg`。程式會：

- 去掉音檔（X3 不能播聲音），大小從幾百 MB 縮到幾 MB
- 把簡體中文轉成臺灣正體（日文和英文不動）
- 子牌組各自成一副：英文卡組會變成「讀」「寫」兩副

目前針對這兩種卡組調整過卡面：

| 卡組 | 正面 | 背面 |
|---|---|---|
| 新標日（初／中／高級） | 假名、詞性 | 漢字寫法、假名、詞性、釋義、第幾課 |
| 實用英語「讀」 | 單字、音標、用法、一句英文例句 | 中英釋義、例句（附翻譯） |
| 實用英語「寫」 | 詞性、中英釋義、一句中文例句 | 單字、音標、釋義、例句 |

其他卡組走通用格式：正面是第一個欄位，背面是其餘欄位。

## 2. 產生卡面字型（日文、韓文、音標）

內建字型只有繁體中文，所以需要另外放一套字型到 SD 卡。在 Windows 上執行：

```bash
pip install freetype-py fonttools
```

```bash
python scripts/anki/build_anki_font.py -o out/fonts/AnkiCJK
```

這套字型是用 Windows 內建的微軟正黑體、游ゴシック、맑은 고딕、Segoe UI 疊出來的，涵蓋繁中、日文、韓文、IPA 音標。
這些字型的授權只限自己的電腦和裝置使用，**產生的檔案不要公開散布**。

日文漢字會用微軟正黑體的字形顯示（例如「直」「骨」是繁中寫法）。

## 3. 放到 SD 卡

```
SD 卡
├── anki/
│   ├── 新標日·初級.xdk
│   ├── 實用英語·基礎詞·讀.xdk
│   └── ...
└── fonts/
    └── AnkiCJK/
        ├── AnkiCJK_14.cpfont
        └── AnkiCJK_22.cpfont
```

第一次打開牌組時，X3 會在旁邊建立同名的 `.srs` 進度檔。**之後更新 `.xdk` 時不要刪掉 `.srs`**：
只要來源牌組相同，重新轉換、覆蓋 `.xdk` 不會影響進度。換成不同的牌組時，舊進度會自動改名成 `.srs.bak` 留著。

## 4. 在 X3 上使用

首頁工具列的「單字卡」（其他主題在首頁選單裡）。

### 牌組清單

| 按鍵 | 功能 |
|---|---|
| 左／右、側鍵 | 選牌組 |
| 確認 | 開始複習 |
| 長按確認 | 牌組設定：每日新卡數、每日複習上限 |
| 返回 | 回首頁 |

每副牌組下面會顯示今天的「新卡／學習中／待複習」張數。

### 複習

前面四顆鍵由左到右是：返回、確認、左、右。

| 畫面 | 返回 | 確認 | 左 | 右 | 側鍵 |
|---|---|---|---|---|---|
| 正面（題目） | 離開 | 翻面 | 翻面 | 翻面 | 翻面 |
| 背面（答案） | **重來** | **困難** | **良好** | **簡單** | 背面太長時換頁 |

- 背面的按鍵提示會寫下一次多久後出現，例如「良好 3天」
- 正面時**長按確認**：撤銷上一張的評分
- 背面時**長按返回**：不評分，直接離開
- 每張評分後立刻寫進 SD 卡，隨時關機都不會掉進度

## 注意事項

- 到期日靠 X3 的時鐘。時鐘沒校正時，牌組清單底部會提示；請在「設定」裡用 WiFi 校時。
- 英文常用詞、進階詞各有兩萬多張，建議每日新卡數先設 10～20 張。
