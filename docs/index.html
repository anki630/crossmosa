整台機器，說中文

開機第一眼就是繁體中文。選單、設定、每一句提示，全是台灣用語。連「憨」「璐」這類書名裡的冷僻字，都顯示得出來2。

翻頁，跟得上你

你還在讀這一頁，下一頁已經備好。大多時候更快；任何時候，都不會更慢1。

無線傳書，無限藏書

電腦或手機連上機器的網址，書拖進去就傳好了。不裝 App、不拔卡。

查註腳，不怕迷路

正文與註釋，像實體書一樣往返——短按電源鍵跳過去、再跳回來，讀到哪裡不會丟。譯注多的書，終於好讀了。

你的書庫，無線上架

電腦上用 Calibre（免費書庫軟體）管書的話，X3 直接連上它：瀏覽、下載、開書，全在機器上完成(OPDS)。

STORY

為什麼會有這個版本

我是電子書閱讀器的愛用者。有工作、有小孩，能讀書的時間都是擠出來的零碎片段——通勤的路上、孩子睡著後的半小時。X3 這種放得進口袋的機器，就是為這些片段準備的。

但買來才發現，它不是為中文讀者做的：選單是英文，中文書打開是滿頁方塊。零碎時間已經夠少了，不該再花在跟機器搏鬥上。

原版 CrossPoint 是個很好的開源起點，所以我從它出發，為自己改了一版。字型放不下就重做字集，記憶體不夠就一 KB 一 KB 地省，翻頁慢就去面板刷新的空檔裡偷時間。改到第 113 個內部版本4，我覺得可以拿出來了。

這一版叫 CrossMosa:Cross 來自它的起點，Mosa 來自 Formosa。開機畫面上那隻是台灣黑熊，牠頭上有一彎月牙。

如果你的閱讀時間也是擠出來的，這一版就是為你調的。

—— anki630，CrossMosa 維護者

WHAT'S NEW

這一版更新了什麼

1.2.0 · 2026 年 8 月。完整紀錄見 CHANGELOG。
最新的 2.0.0-rc.1（測試版）支援新批次 X3 的 UC8279 面板，換章與翻頁也快了不少。

有些書打不開，現在打得開了

  • 開書直接顯示「全書完」。有些 EPUB 開起來書在、頁數是零、一個字都讀不到。原因是目次檔的元素名帶了命名空間前綴(<ns0:package>)。EPUB 規格允許這樣寫，只是不常見。解析器只認裸名，於是收到 0 筆章節——而 0 筆章節在閱讀器裡看起來，就是「你已經讀完了」。
  • 書名與作者就這樣不見了。上面那個修法本身有個陷阱:書目欄位的目標字串自己就帶前綴，只改一半會讓它們永遠對不上。一併處理了。
  • 主畫面的封面變成空框。這是前一個問題的後遺症:書「壞掉」期間縮圖產生失敗，程式寫了一個 0 byte 的檔案當作「這本沒有封面」的記號，於是修好之後封面也回不來。現在會辨認出這種記號並重新產生。

閱讀選單重整

  • 14 項 → 12 項，並依「你為什麼開這個選單」重排:先是位置（選擇章節、註腳、書籤、跳至指定進度），接著是邊看邊調的排版（字級、行距、粗體），一次性的設定與工具放最後。
  • 拿掉「回主畫面」與「截圖」。這兩項的功能都還在，拿掉的是重複的入口:閱讀中按 Back 鍵本來就回得了主畫面，截圖有全域組合鍵電源 + 下在任何畫面都有效。原本的路徑比開選單快。
  • 設定裡那個按下去沒有反應的「藍牙翻頁器」也移除了。藍牙功能早就關閉，只有這個條目忘了跟著拿掉。

升級注意

  • 沒有變更任何快取格式——既有的書不會重新排版，閱讀進度、書籤、設定都不受影響。
  • 之前遇過「全書完」或「封面空框」的書，刷完會自己復原，不需要手動刪 SD 卡上的 /.crossmosa。
  • 閱讀選單的順序變了，習慣用位置記憶按的話第一次要看一眼。

INSTALL

三步驟，十五分鐘裝好

機器你已經有了，SD 卡就插在上面。剩下的只有三步。

刷韌體
把 zip 裡的 update.bin 用讀卡機放進 SD 卡根目錄，插回機器。關機，按住左側鍵+電源。五分鐘後，它就是 CrossMosa 了。
放字型（跳過這步，書打開仍是方塊）
把字型包解壓縮到 SD 卡的 /.fonts/。內文字型在 SD 卡上、不在韌體裡。刷完看到方塊不是刷壞了，是字型還沒放。
讀第一本書
把附的《歡迎使用 CrossMosa》複製進 SD 卡，開機就是繁體中文，打開它。再花十分鐘讀完，你就是熟手。
開始讀之前，對一下這張清單——五格全勾，體驗最完整；前四格就能開讀：
☐ 韌體已刷（update.bin 放 SD 根目錄）
☐ 字型資料夾在 /.fonts/（缺這步=滿頁方塊）
☐ 《歡迎使用 CrossMosa》已複製進 SD 卡
☐ 閱讀字型已選：設定 → 閱讀器 → 閱讀字型
☐ （可選）名畫放進 /.sleep/，待機變畫框
開機就是繁體中文，不用設定——它本來就該如此。
電腦偵測不到機器？本來就不用接。首刷全程走 SD 卡，檔案用讀卡機放進卡。維護者的 Mac 接了 Hub 也偵測不到，索性整個流程改走 SD。線材、Hub、甚至 USB 被鎖，都不影響。完整說明與退路在 安裝文件。

FAQ

猶豫的話，先看這裡

會把機器刷壞嗎？
風險很低。首刷用的是原廠韌體自己的 SD 更新機制；而且 CrossMosa 保留了救援模式：關機後按住左側翻頁鍵再開機，直接進 SD 卡韌體選擇畫面——就算刷了一版開不了機的韌體，也有路回來。風險與退路，安裝文件寫得很白。
以後怎麼更新？
出新版時，到 Release 下載單獨那顆 update.bin（免解壓），手機開瀏覽器連上機器的網頁傳輸把它丟進 SD 卡，再到「設定 → 系統 → SD 卡韌體更新」點一下——全程不用電腦。
可以刷回去嗎？
可以，隨時。SD 卡救援模式（關機按住左側鍵再開機）能刷回原版 CrossPoint 韌體，不用電腦；要回原廠韌體，用原廠的更新檔或網頁 flasher。來去自由。
跟原版 CrossPoint 差在哪？
CrossMosa 基於 CrossPoint 1.4.1，重做了中文字集與介面翻譯、加了翻頁預取、OPDS 中文書庫體驗、名畫待機策展、隨附教學書，並修了一批記憶體與穩定性問題。完整差異列表在 GitHub。
要錢嗎？
免費，開源（MIT 授權），原始碼全部公開。覺得好用的話，頁尾有幾種支持的方式，完全自願。
書從哪裡來？
本專案不提供書，也不處理 DRM。請向正版管道購買、認明「無 DRM」的書（Readmoo、樂天 Kobo、Google Play 圖書都有部分書籍如此，依平台與書而定），搭配 Calibre 整理後用網頁上傳或 OPDS 傳進機器。有 DRM 的書，這台機器讀不了。
沒有 X3 也能用嗎？
CrossMosa 目前只為 Xteink X3 調校。X3 是一台口袋大小、58 克的電子紙閱讀器，在 Xteink 官方通路買得到——本專案與 Xteink 無任何關係，純粹是為這台機器做的愛好者韌體。
