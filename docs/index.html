INSTALL

三步驟，今晚就能開始讀

機器你已經有了，SD 卡就插在上面。剩下的只有三步。

適用機型：Xteink X3、X4。觸控的 X4 Pro 和其他機型都不適用。

該下載哪一版？下載最新的正式版就好，X3、X4 都能直接刷。想先試還在測試的新功能，可以到下載頁找 Beta 版。

刷機（只有第一次）
從下載頁下載 update.bin，放進 SD 卡最外層，插回機器。關機後，按住下面兩顆鍵開機，看到載入畫面就放手：
X3：左側的上一頁鍵＋電源鍵
X4：右側上面那顆鍵＋電源鍵。沒有反應的話，接上 USB 電源再試一次。
等它自己重新開機，就完成了。
放字型
下載字型包，在 SD 卡最外層建一個 fonts 資料夾，把字型包裡的資料夾放進去。沒有字型，書會顯示成方塊。
開始讀
在剛剛下載韌體的那一頁，下載使用手冊 CrossMosa.epub，放進 SD 卡。到「設定 → 閱讀器 → 閱讀字型」選一套字型，打開手冊，一邊讀一邊按。

以後更新，不用重刷。把新版傳進機器，到「設定 → 系統 → SD 卡韌體更新」選它就好，不用再按鍵開機。

想讓待機畫面變成名畫，照這份說明放進 SD 卡就好。遇到問題，看完整的安裝說明。

FAQ

猶豫的話，先看這裡

支援哪些機器？
Xteink X3 和 X4。觸控的 X4 Pro 不支援。
每次更新都要重刷嗎？
不用。只有第一次要按鍵刷機。之後出新版，用手機的瀏覽器把它傳進機器，到「設定 → 系統 → SD 卡韌體更新」選它就好，全程不用接線。
不太會用電腦，也裝得起來嗎？
裝得起來。用電腦或手機把檔案放進 SD 卡，再按住兩顆鍵開機就好，機器不用接線。
會把機器刷壞嗎？
刷機有風險，而且不是每一次都救得回來。開始之前，請先讀完安裝說明裡的注意事項。
可以刷回原廠系統嗎？
可以。社群整理了刷回原廠的步驟（英文）：機器接得上電腦的話，用 CrossPoint 的刷機網站；USB 被鎖住的 X3，改用 SD 卡和原廠的更新檔。
要錢嗎？
免費，開源。
書從哪裡來？
CrossMosa 不提供書。請向正版管道購買沒有 DRM 的電子書，再用瀏覽器傳進機器。有 DRM 的書，這台機器讀不了。
跟原版 CrossPoint 差在哪？
CrossPoint 是很好的開源起點。CrossMosa 在它上面，把中文閱讀做完整。

STORY

為什麼會有它

我是電子書閱讀器的愛用者。有工作、有小孩，能讀書的時間都是擠出來的零碎片段——通勤的路上、孩子睡著後的半小時。X3 這種放得進口袋的機器，就是為這些片段準備的。

但買來才發現，它不是為中文讀者做的：選單是英文，中文書打開是滿頁方塊。零碎時間已經夠少了，不該再花在跟機器搏鬥上。

所以我從開源的 CrossPoint 出發，為自己改了一版。一版一版地改，改到我覺得可以拿出來了。

它叫 CrossMosa：Cross 來自它的起點，Mosa 來自 Formosa。開機畫面上那隻是台灣黑熊，牠頭上有一彎月牙。

如果你的閱讀時間也是擠出來的，這一版就是為你調的。

—— anki630，CrossMosa 維護者
