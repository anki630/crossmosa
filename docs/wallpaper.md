# 換待機名畫

2.0.1 的下載頁附了一包名畫：五十幅世界名畫，都取自 Wikimedia Commons 的公共領域作品，每一幅都為電子紙重新調過。

1. 下載[名畫包](https://github.com/anki630/crossmosa/releases/download/v2.0.1/crossmosa-2.0.1-wallpapers.zip)，解壓縮。
2. 在 SD 卡最外層建一個 `sleep` 資料夾，把 `.bmp` 檔放進去。放兩張以上才會輪流顯示。已經放在 `.sleep` 資料夾的不用搬。
3. 在機器上打開：設定 → 顯示 → 待機畫面 → 自訂。

SD 卡最外層不要放單獨一張 `sleep.bmp`，它會優先顯示，而且不會輪換。

想換成自己的圖：轉檔工具和選畫清單在 [`wallpapers/`](../wallpapers/)。

# Changing the sleep screen (English)

The 2.0.1 download page includes a pack of fifty famous artworks. Every image is a public-domain work from Wikimedia Commons and has been adjusted for the e-paper display.

1. Download and extract the [artwork pack](https://github.com/anki630/crossmosa/releases/download/v2.0.1/crossmosa-2.0.1-wallpapers.zip).
2. Create a `sleep` folder in the root of the SD card and put the `.bmp` files inside it. Add at least two images to rotate between them. You do not need to move images already stored in `.sleep`.
3. On the device, open Settings → Display → Sleep Screen → Custom.

Do not put a single `sleep.bmp` file in the root of the SD card. It takes priority and does not rotate.

To use your own images, see the conversion tool and artwork list in [`wallpapers/`](../wallpapers/).
