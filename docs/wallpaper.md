# 桌布

闔上的時候，螢幕上是一幅畫。桌布一個系列一包，放進 SD 卡就能用。

## 名畫系列

五十幅世界名畫，都取自 Wikimedia Commons 的公共領域作品，每一幅都為電子紙重新調過。

[下載 X3 版](https://github.com/anki630/crossmosa/releases/download/wallpapers-masterpieces-2026-09/crossmosa-wallpapers-masterpieces-x3-2026-09.zip) · [下載 X4 版](https://github.com/anki630/crossmosa/releases/download/wallpapers-masterpieces-2026-09/crossmosa-wallpapers-masterpieces-x4-2026-09.zip)

兩台的螢幕尺寸不同，請下載跟你的機器相同的那一包。

## 安裝

1. 解壓縮。
2. 在 SD 卡最外層建一個 `sleep` 資料夾，把 `.bmp` 檔放進去。放兩張以上才會輪流顯示。已經放在 `.sleep` 資料夾的不用搬。
3. 在機器上打開：設定 → 顯示 → 待機畫面 → 自訂。

橫式的畫是轉 90 度存的，看的時候把機器往逆時針方向轉。

SD 卡最外層不要放單獨一張 `sleep.bmp`，它會優先顯示，而且不會輪換。

想換成自己的圖：轉檔工具和選畫清單在 [`wallpapers/`](../wallpapers/)。

# Wallpapers (English)

When the device is closed, a painting stays on the screen. Each wallpaper series is a separate pack. Copy it to the SD card to use it.

## Masterpieces

Fifty famous paintings. Each one is a public-domain work from Wikimedia Commons and has been adjusted for the e-paper display.

[Download for X3](https://github.com/anki630/crossmosa/releases/download/wallpapers-masterpieces-2026-09/crossmosa-wallpapers-masterpieces-x3-2026-09.zip) · [Download for X4](https://github.com/anki630/crossmosa/releases/download/wallpapers-masterpieces-2026-09/crossmosa-wallpapers-masterpieces-x4-2026-09.zip)

The two devices have different screen sizes. Download the pack for your device.

## Installation

1. Extract the zip file.
2. Create a `sleep` folder in the root of the SD card and put the `.bmp` files inside it. Add at least two images to rotate between them. You do not need to move images already stored in `.sleep`.
3. On the device, open Settings → Display → Sleep Screen → Custom.

Landscape paintings are stored rotated by 90 degrees. Turn the device counter-clockwise to view them.

Do not put a single `sleep.bmp` file in the root of the SD card. It takes priority and does not rotate.

To use your own images, see the conversion tool and artwork list in [`wallpapers/`](../wallpapers/).
