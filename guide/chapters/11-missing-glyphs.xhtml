11　遇到方塊字

你會遇到。先分清楚是哪一種。

選單、檔名、書名、目錄出現 □。那是內建介面字型缺字。它收了常用漢字，加上掃描整個電子書庫挑出來的字，但不是全部的中文。這套字型在韌體裡，換 SD 卡沒有用。

書的內文出現 □。那是 SD 卡字型缺字，換一套涵蓋更廣的就好——明體幾乎不會缺。

所以「書名在檔案清單上是方塊，打開之後內文完全正常」是預期行為，不是壞掉。

已知的洞：很多台灣人名用字根本不在 BIG5 裡面。最常見的幾個（喆、堃、彣）已經補進來了；再冷僻的，回報給我們。

看到方塊，去 GitHub 開一個 Issue，標題寫「缺字」，內文把那個字本身貼上來，再說它出現在哪裡。補字是例行維護，不是什麼大工程。
